# ALL:GOLF (시연용)

골프장 검색·시연 예약 앱, 골프장 관리자(`/partner/`), 본사 관리자(`/admin/`), 투자·제휴 시연 허브(`/demo/`)로 구성된 **시연용** 프로젝트입니다.
실제 결제·실제 골프장 예약·외부 골프장 API 연동은 없습니다.

- 정적 사이트: <https://neved12.github.io/all-golf-test/> — 서버 없이 **정적 시연 모드**로 동작합니다.
- 시연 허브: <https://neved12.github.io/all-golf-test/demo/> — 투자자·골프장 제휴 시연 가이드, 사업성 시뮬레이터.
- 서버 실행 시: 같은 주소에서 앱과 API·DB가 함께 동작합니다(10단계: 원클릭 시연 데이터·시연 허브·사업성 시뮬레이터).

## 빠른 시작 (Windows 집 PC 포함)

```bash
git pull
npm start            # = node server/index.js
npm run demo:stage10 # (선택) 투자·제휴 시연용 데이터 한 번에 준비
```

Windows에서는 `start-server.bat` 더블클릭으로도 실행됩니다.
**`npm install` 은 필요하지 않습니다** — 외부 패키지와 네이티브 모듈(C++ 컴파일러)을 쓰지 않습니다. Node.js 18 이상만 있으면 됩니다.

### 관리자 계정

- 본사 관리자: 환경변수 `ADMIN_PASSWORD` 로 지정합니다.
  지정하지 않으면 **시연용 기본 비밀번호 `allgolf-demo-2026`** 으로 실행되고 시작 로그에 경고가 표시됩니다.
  이 값은 저장소에 공개된 시연용 값이며 실제 운영 계정이 아닙니다.
- 골프장 담당자: 본사 관리자 화면 → **제휴 계정 관리**에서 제휴 승인된 골프장별로 발급합니다(초기 비밀번호는 1회 표시).
  시연 편의를 위해 아래 명령으로 승인 골프장마다 계정을 한 번에 만들 수도 있습니다.

  ```bash
  npm run demo:partner-accounts            # 시연용 기본 비밀번호 allgolf-partner-2026
  npm run demo:partner-accounts -- 원하는비밀번호
  ```

  또는 서버를 `ALLGOLF_SEED_DEMO_PARTNER_ACCOUNTS=1` 로 실행하면 승인 골프장에 계정이 자동 생성됩니다(시연 전용).
  `npm run demo:stage10` 은 시연 대상 3곳(우정힐스·세종에머슨·프린세스)에 계정을 함께 만듭니다(비밀번호 `allgolf-partner-2026`).
  계정 비밀번호는 scrypt 해시로만 저장되며 평문은 DB·Git에 남지 않습니다.

### 환경변수

`.env.example` 을 `.env` 로 복사해 값을 채웁니다(`.env` 는 Git 에 올라가지 않습니다).
`ADMIN_PASSWORD`, `SESSION_SECRET`, `PARTNER_SESSION_TTL_HOURS`, `DEMO_PARTNER_PASSWORD`,
`ALLGOLF_SEED_DEMO_PARTNER_ACCOUNTS` 등을 설명과 함께 제공합니다.

## 10단계에서 달라진 점 (투자·제휴 시연 패키지)

- **원클릭 시연 데이터**: `npm run demo:stage10` (또는 `/demo/` 화면의 “시연 데이터 준비”)으로
  제휴 골프장 3곳·티타임 84건(3곳 × 7일 × 4시간)·담당자 계정 3개·예약 68건·정산서 3건을 만듭니다.
  만든 레코드에는 `demoStage: 'stage10'` + `demoBatch` 태그가 붙고, 이전 시연 배치는 태그 기준으로만 정리합니다.
- **시연 데이터 초기화**: `npm run demo:stage10 -- reset` (대화형은 `RESET` 입력, 비대화형은 `--yes`) 또는 화면의 초기화 버튼.
  확인 문구 `RESET-STAGE10-DEMO` 와 확인 체크가 있어야 실행되며, **태그가 붙은 시연 레코드만** 삭제합니다.
  일반 데이터(직접 승인한 골프장·수동 티타임·예약·정산서)는 그대로 남습니다. 삭제 전 DB 백업이 자동 생성됩니다.
- **시연 허브 `/demo/`**: **투자자 시연 모드**(509곳 → 68곳 예약·재고 차감 → 본사 통계·정산 → 수익 흐름)와
  **골프장 제휴 시연 모드**(제휴 신청 → 본사 승인 → 담당자 로그인 → 티타임·특가 등록 → 예약·취소 → 정산서 확인)를
  단계별 가이드·체크리스트(진행률 저장)·바로가기 링크로 제공합니다. 사용자 앱 홈·본사/골프장 관리자 사이드바에서도 들어갈 수 있습니다.
- **사업성 시뮬레이터**: 제휴 골프장 수, 골프장당 일평균 예약 팀, 평균 예약 거래액, 수수료율(0~30%), 월 영업일수를 조절하면
  월 예약 팀 수·월 GMV·월/연 플랫폼 수수료 매출을 즉시 계산하고 결과 요약을 복사할 수 있습니다.
  실제 실적이 아닌 **가정 기반 시연 계산치**(취소·환불·세금·운영비 미반영, 수수료 기준 별도 계약 필요)임을 화면에 표시합니다.
- **서버 API**: `GET /api/demo/stage10`(공개 상태: 개수·배치만, 개인정보 없음),
  `POST /api/demo/stage10/stage`·`POST /api/demo/stage10/reset`(본사 관리자 인증 + 확인 문구 필수).

## 9단계 기능 (본사 운영 자동화)

- **운영 통계·제휴 성과**(`/admin/` → 운영 통계·제휴 성과): 기간(오늘/최근 7일/최근 30일/전체)별 예약 건수, GMV, 취소·환불액,
  노쇼율, 1·2·3부 분포, 제휴 신청 승인 전환율을 골프장별로 집계합니다. 기간은 **예약 접수일**, 정산서는 **라운드일** 기준입니다.
  집계 결과를 CSV(UTF-8 BOM)·JSON 으로 내보낼 수 있습니다.
- **수수료율**: 골프장별로 기본 8%, 0~30% 범위에서 설정합니다(버전 충돌 409, 감사 로그). 정산서는 생성 시점 수수료율을 스냅샷으로 보관합니다.
- **정산 시뮬레이션**(`/api/admin/settlements`): 정산 기준액 = GMV + 취소 수수료, 플랫폼 수수료 = 기준액 × 수수료율,
  정산 예정액 = 기준액 − 수수료. 정산서는 `DRAFT → PENDING → CONFIRMED → PAID` 로만 전이하며, 같은/겹치는 기간 중복 생성은 `409`입니다.
- **골프장 담당자**: `/partner/` 에서 본인 골프장의 정산 내역·수수료 상세·알림 로그만 조회합니다(타 골프장 `403`, 생성·전이 `403`).
- **운영 알림 시뮬레이션 로그**: 예약 확정·취소, 정산 확정·지급 시 수신 대상·채널·제목·요약·시각·상태(`simulated`)를 DB 에 기록합니다.
  **실제 문자·푸시·PG·계좌 이체는 없습니다.**

## 8단계 기능 (서버 예약 엔진)

- **임시확보(Hold)**: 고객이 결제 화면을 열면 서버가 5분간 1팀을 잡아 둡니다(TTL 만료 시 자동 해제·재고 복구).
- **원자적 예약 확정**: 파일 DB 잠금 안에서 잔여 팀을 검증·차감합니다. 같은 티타임에 동시에 여러 명이 예약해도
  마지막 1팀은 정확히 한 건만 성공하고 나머지는 `409 Conflict`로 막힙니다(Overbooking 방지).
- **멱등 키**: `Idempotency-Key` 헤더로 중복 클릭·재전송을 막습니다. 같은 키는 이중 차감 없이 동일 예약을 돌려줍니다.
- **예약 조회·취소·환불**: 예약번호(`AG-YYMMDD-NNNNN`) + 예약자 연락처로 조회하고, 서버가 취소·환불 규정으로
  수수료·환불액을 계산합니다. 취소 즉시 잔여 팀이 복구됩니다.
- **실시간 재고 공유**: 고객 앱은 `inventoryLinked:true`로 전환되어 서버 재고를 그대로 표시하고, SSE로 즉시 갱신합니다.
  서버가 없는 GitHub Pages에서는 기존 localStorage 시연 모드(요청 0건)로 폴백합니다.

## 7단계 기능 (골프장별 계정·권한)

- **골프장별 담당자 계정**: 제휴 승인된 골프장에만 계정 발급, 서버 로그인/로그아웃, 계정 비활성화·권한 변경 시 기존 세션 즉시 무효화.
- **데이터 격리**: 담당자는 자기 골프장의 티타임·요금·특가만 조회·수정할 수 있습니다. 다른 골프장 ID로 요청하면 `403`.
- **티타임 서버 CRUD**: 코스·날짜·시간·부·예약 가능 팀·최대 인원·기본 그린피·상태. 중복 등록과 수정 충돌(`409`, version) 방어,
  예약·임시확보·특가가 연결된 티타임 삭제 차단. 최대 90일 날짜 반복 등록.
- **요금·특가 서버 CRUD**: 기본/3인/4인 그린피, 카트·캐디·예약금, 취소·환불 정책, 특가 금액·판매 기간·적용 팀·노출 여부와 할인율 계산.

## 1~6단계 기능

- **1단계** 전국 골프장 데이터·검색·상세·시연 예약 기본 흐름.
- **2·3단계** 모바일 UI/UX, 재방문(찜·최근 본·최근 검색), 공유 링크, 예약 대기, `.ics` 캘린더 저장.
- **4단계** 공개 배포(GitHub Pages)·보안 헤더·중복 파일 정리.
- **5단계** 골프장 제휴 신청·본사 승인/반려 흐름(접수번호 조회).
- **6단계** 외부 패키지 없는 순수 Node.js 서버, 원자적 파일 DB(`server/data/db.json`), HMAC 관리자 인증, SSE/폴링, 정적 폴백.

## 전국 골프장 데이터 (509곳)

- `data/national-golf-courses.js` — 문화체육관광부 전국 골프장 현황, 행정안전부 생활_골프장(골프장업 인허가), 한국골프장경영협회 2025 가이드북 회원사 명부를 병합한 **조회용** 목록입니다(기준일 2024-12-31, 생성 2026-11-26).
- **509곳 = 시연 예약 68곳 + 정보 제공 전용 441곳**. 정보 제공 골프장은 가격·티타임을 표시하지 않고 제휴 신청만 안내합니다.
- 시연 예약 68곳의 티타임·재고는 시연용 가상 데이터이며 실제 골프장 재고가 아닙니다.

```bash

node tests/run-stage7-scenarios.js    # 7단계 계정·권한·티타임·특가 187개
node tests/run-stage8-scenarios.js    # 8단계 예약·Hold·동시성·멱등·취소·환불 168개
node tests/run-stage9-scenarios.js    # 9단계 통계·수수료·정산·알림·DB v4 200개
node tests/run-stage10-scenarios.js   # 10단계 시뮬레이터·시연 데이터 준비/초기화·CLI·격리 113개
```

  GitHub Pages 배포본은 실브라우저로 화면·콘솔 오류·모바일 360px 가로 넘침을 확인합니다(검증 결과는 10단계 보고서 참조).

## 데이터·백업

- 서버 DB: `server/data/db.json` (Git 제외, 개인정보 포함 가능)

- 수동 백업/복구: `npm run db:backup`, `npm run db:restore -- <파일>`
- 자세한 내용: [`server/data/README.md`](server/data/README.md)
