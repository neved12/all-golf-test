시연 데이터 준비·초기화

시연용 데이터만 따로 준비하고 되돌립니다. 일반 데이터(직접 입력·승인한 골프장·예약)는 건드리지 않습니다.

1. 시연 데이터 준비

제휴 골프장 3곳(우정힐스·세종에머슨·프린세스)에 오늘부터 7일 치 티타임 84건, 담당자 계정 3개, 예약·정산서를 만듭니다. 이미 있는 레코드는 건드리지 않고, 이전 10단계 시연 배치만 정리 후 다시 만듭니다.

로그인 전

2. 초기 시연 상태로 되돌리기

10단계 시연 배치(태그 demoStage=stage10)만 삭제합니다. 일반 데이터는 유지되며, 삭제 전 DB 백업이 자동으로 만들어집니다.

정적 배포에서는 서버 DB가 없으므로 이 브라우저에 저장된 시연 데이터만 비웁니다.

시연 시 알아 둘 점

  • 실제 골프장 예약·결제·환불·계좌 이체·문자 발송은 없습니다. 모든 기록은 시연용입니다.
  • 정적 배포(GitHub Pages)에서는 서버 없이 브라우저 시연 모드로 동작하며, 서버 기능 요청은 보내지 않습니다.
  • 사업성 시뮬레이터는 가정 기반 시연 계산치입니다. 취소·환불·세금·운영비와 실제 계약 조건은 반영하지 않았습니다.
  • 시연 데이터 초기화는 10단계 태그가 붙은 레코드만 지웁니다.
