# ALL:GOLF 전국 골프장 데이터 검증 보고서

작성일: 2026-10-13  
사용자 화면에 표시되는 공식 명부 기준일: 2024-12-08

## 1. 이번 구축 범위

- 한국골프장경영협회 2025 가이드북의 회원사 현황 표를 구조화했다.
- 협회 명부 203곳과 기존 ALL:GOLF 충청권 마스터 68곳을 이름·지역 기준으로 병합했다.
- 기존 충청권 골프장 ID를 우선 보존했다.
- 27개 중복 레코드를 병합하여 최종 244개의 고유 ID를 만들었다.
- 확인되지 않은 실제 요금·티타임·제휴 여부는 생성하지 않았다.
- 기존 68곳의 예약 기능은 `시연 예약`으로 유지하고, 나머지 176곳은 정보 조회 전용으로 분리했다.

## 2. 출처

1. [한국골프장경영협회 2025 가이드북 회원사 현황](https://www.kgba.co.kr/guidebook/2025/guidebook2025_04.pdf)
   - 명부 자체 표기 기준일: 2024-12-08
   - 사용 필드: 골프장명, 회원제 홀 수, 대중제 홀 수, 주소, 전화번호
   - 협회 회원사 명부이므로 대한민국의 모든 비회원 골프장을 포함하는 완전한 행정 등록 목록은 아니다.
2. [한국국토정보공사 공간화-전국 골프장 현황](https://geomarket.kr/user/dataset/view.do?data_sn=1202)
   - 생성일 2024-12-10, 사이트 표시 업데이트일 2026-04-10
   - 전체 ZIP은 로그인 및 이용목적 제출 절차가 필요하여 이번 실행 환경에서 원본 레코드를 내려받지 못했다.
   - 따라서 이 자료는 교차검증 후보로 기록했으며 최종 244개 레코드 생성에는 직접 사용하지 않았다.
3. 기존 `data/golf-courses.js`에 기록된 골프장 공식 홈페이지 및 공개 출처
   - 협회 명부에 없는 충청권 41곳을 보완한다.
   - 해당 레코드는 공식 명부 검증 완료 레코드와 별도로 구분한다.

## 5. 데이터 구조

- `data/national-golf-courses.js`: 협회 명부에서 생성한 전국 정보용 레코드
- `data/golf-courses.js`: 기존 ID를 우선하는 병합 계층 및 전국 지역 설정
- `data/demo-teetimes.js`: 기존 충청권 시연 예약 재고만 생성
- `scripts/import-kgba-courses.js`: 협회 PDF를 다시 구조화하는 재현 스크립트

정보 전용 골프장은 다음 원칙을 따른다.

- `bookingStatus: "info"`
- `dataMode: "official_info"`
- 실제 가격, 티타임, 잔여팀을 생성하지 않음
- 사용자 화면에서 `ALL:GOLF 예약 미지원` 표시

기존 시연 예약 골프장은 다음 원칙을 따른다.

- 기존 ID 유지
- `bookingStatus: "demo"`
- `demo-teetimes.js`의 시연 가격·티타임만 사용
- 실제 판매 및 결제가 아님을 화면에 표시

## 6. 한계와 다음 검증 단계

이번 데이터는 전국 서비스의 1차 공식 기반 목록이며 행정 등록 기준의 완전한 전국 전수 데이터가 아니다. 다음 단계가 필요하다.

1. 한국국토정보공사 원본 ZIP 사용 승인을 받아 협회 비회원 골프장을 추가한다.
2. 시도별 체육시설업 등록자료로 운영 중·폐업 상태를 교차검증한다.
3. 골프장 공식 홈페이지를 확인해 현재 명칭, 홈페이지, 예약 URL, 코스명을 보완한다.
4. 주소 정규화와 위·경도 지오코딩은 별도 출처 및 이용조건 검토 후 수행한다.
5. 실제 예약 지원 전에는 제휴 계약과 ERP/API 또는 관리자 수동 재고 등록을 완료한다.

## 7. 재현 방법

협회 PDF를 `data/sources/kgba-2025-member-courses.pdf`에 둔 뒤 `pdfjs-dist`가 포함된 `NODE_PATH`로 아래 명령을 실행한다.

```powershell
node scripts/import-kgba-courses.js
```

생성 파일을 변경한 뒤에는 다음 회귀 검사를 실행한다.

```powershell
node tests/national-search-regression.js
node tests/feedback-regression.js
```
