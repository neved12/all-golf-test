## 5. 포함·제외 기준

### 포함

1. 문체부 「전국 골프장 현황」에 등록된 **코스 골프장**(회원제·대중제·비회원제, 6홀 이상 실제 코스).
2. 협회 회원사 명부에 있으나 문체부 등록 현황에 없는 골프장. 예: 군 체력단련장(남서울CC, 88골프장, 계룡대 등)은
   체육시설업 등록 대상이 아니어서 문체부 명부에 없지만 실제 운영 중인 코스 골프장이므로 유지했습니다.
3. 행정안전부 인허가에 **영업/정상**으로 등록되어 있으면서 문체부·협회 명부에 없는 골프장 12곳(신규 개장·명부 누락).
   - 경기: 크리스밸리CC(안성, 2025-12 인허가), 헤르몬GC(여주, 2026-10)
   - 강원: 레익스빌골프장(속초), 남한강에스파크 컨트리클럽(원주, 2026-02), 알프스퍼블릭(고성, 9홀 대중)
   - 인천: 베어즈베스트청라골프클럽(청라), 인천국제공항스카이칠십이골프장(영종)
   - 대구: 산타크로스골프장(군위, 2024-01), 수서컨트리클럽(군위, 2026-06)
   - 전남: 나주혁신도시 부영CC(나주)
   - 경북: 노블레스CC&리조트(칠곡, 2026-05), 롯데스카이힐성주컨트리클럽(성주)

### 제외

1. **폐업·휴업·직권말소**: 인허가가 영업/정상이 아닌 골프장 1곳을 제외했습니다.
   - `cosmos 1`(전남 영암, 휴업). 폐업 라이선스만 남은 명부 레코드(예: 에덴블루CC 2016 폐업, 여주썬밸리 2024 폐업)도 함께 제외했습니다.
2. **실내·연습장·부속시설·간이 골프장** 11건
   | 사업장명 | 사유 |
   |---|---|
   | (재)한국군사문제연구원남성대쌍둥이골프연습장 | 골프연습장 |
   | 태흥골프연습장 | 골프연습장 |
   | 고흥골프장 | 주소가 골프연습장, 코스 골프장으로 확인되지 않음 |
   | (주)송산골프랜드 / 송산 | 익산 석암동 골프연습장·부속시설 |
   | 금과간이골프장 | 간이(파3) 골프장 |
   | 대중제 골프장(9홀) | 이천 장호원읍 단지의 9홀 부분 코스로 보여 별도 골프장으로 세지 않음 |
   | 파라다이스골프장 | 서귀포 광평리 나인브릿지 단지의 옛 라이선스로 판단 |
   | 경원건설(주) | 골프장이 아닌 법인명 라이선스 |
   | 보스당구클럽 | 당구장(원본 데이터 오류) |
   | 미사용 | 휴면 라이선스 |
3. **중복 레코드**: 명칭 변경 전 라이선스 34건은 새 이름의 골프장에 인허가 정보(전화·현행 주소·영업상태)만 붙이고 별도 골프장으로 만들지 않았습니다.
   병합 사유는 `data/national-build-report.json`의 `manualMerges`, 규칙은 `data/sources/localdata-course-map.json`에 남겼습니다.

### 파3·간이·군 체력단련장 기준

- **파3·간이 골프장**: `골프장업`이 아닌 골프연습장업·체력단련장업으로 등록되거나 명칭에 `파3`·`간이`가 있는 경우 제외했습니다.
- **군 체력단련장**: 일반인 이용이 제한된 시설이라도 실제 코스 골프장이고 협회 명부에 있으면 포함하되, `bookingStatus: "info"`(예약 미지원)로 둡니다.
  이번 데이터에서 88골프장(국가보훈부, 용인)·남서울CC·계룡대가 이에 해당합니다.

  - 공통: `id`, `name`, `region`, `city`, `address`, `operationType`, `holes`, `memberHoles`, `publicHoles`,

## 8. 남은 한계와 다음 단계

1. 행정안전부 인허가 데이터는 시설 명칭이 법인명·옛 이름인 경우가 있어, 자동 매칭 후 남은 라이선스를 수동 규칙으로 정리했습니다.
   새 명칭 변경이 생기면 `data/sources/localdata-course-map.json`에 근거와 함께 추가해야 합니다.
2. 운영 형태 미확인 33곳과 홀수 미확인 14곳은 공식 출처에 값이 없어 비워 두었습니다. 골프장 홈페이지·협회 자료로 보완이 필요합니다.
3. 위·경도 좌표는 넣지 않았습니다. 행안부 좌표는 Bessel 중부원점TM(EPSG:5174)이라 변환·검증 없이 넣으면 지도가 어긋납니다. 좌표 변환·지오코딩은 별도 단계로 분리합니다.
4. 실제 예약 지원 전에는 제휴 계약과 ERP/API 또는 관리자 수동 재고 등록이 필요합니다. 정보 전용 골프장은 계속 `bookingStatus: "info"`입니다.
